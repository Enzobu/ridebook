# Invitations administrateur

Un administrateur connecté voit l'entrée `Invitations` dans l'en-tête.

L'écran permet de générer un lien d'invitation, avec un email optionnel. Le lien est valable 1 heure et utilisable une seule fois.

Après génération, le bouton `Copier` place le lien dans le presse-papiers.
