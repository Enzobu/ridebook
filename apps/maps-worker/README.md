# Maps Worker Ridebook

Worker Node.js dédié à la récupération asynchrone des URLs d'intégration Google Maps.

## Commandes

```bash
pnpm --filter maps-worker dev
pnpm --filter maps-worker build
pnpm --filter maps-worker lint
pnpm --filter maps-worker test
```

Le traitement réel des jobs DB et Selenium sera ajouté dans les tickets worker.
